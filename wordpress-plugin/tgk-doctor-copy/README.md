# افزونه TGK Doctor Copy — نسخه اولیه

این پوشه یک اسکلت اولیه افزونه وردپرس برای پروژه «دکتر کپی» است.

## وضعیت فعلی
- شورت‌کد رابط فارسی و راست‌چین: `[tgk_doctor_copy]`
- دریافت برند، مدل، شرح مشکل و تصویر چاپ
- بررسی اولیه نوع فایل و سقف ۴ مگابایت
- مسیر REST API با محدودیت ساده درخواست
- تنظیم آدرس موتور و کلید API در پیشخوان وردپرس
- ارسال درخواست به موتور مستقل از سمت سرور؛ کلید API در مرورگر افشا نمی‌شود
- هیچ تشخیص واقعی در این نسخه انجام نمی‌شود مگر اینکه موتور سازگار به آن متصل شود.

## نصب آزمایشی
1. پوشه `tgk-doctor-copy` را در `wp-content/plugins/` قرار دهید یا به ZIP تبدیل کنید.
2. از پیشخوان وردپرس افزونه را فعال کنید.
3. در یک برگه، شورت‌کد `[tgk_doctor_copy]` را قرار دهید.
4. تا زمانی که موتور تحلیل ساخته نشده، فرم پیام «موتور عیب‌یابی هنوز متصل نشده است» نشان می‌دهد.

## قرارداد API مورد انتظار
درخواست POST به آدرس HTTPS پیکربندی‌شده با هدر `Authorization: Bearer <key>` و JSON زیر ارسال می‌شود:
- `brand`: نام برند
- `model`: مدل (ممکن است خالی باشد)
- `symptoms`: شرح مشکل
- `image_mime`: نوع تصویر
- `image_base64`: محتوای تصویر با Base64

پاسخ موفق مورد انتظار:
```json
{
  "summary": "خلاصه محتاطانه نتیجه",
  "possible_causes": ["علت احتمالی اول", "علت احتمالی دوم"]
}
```

## پیش از عرضه عمومی
این کد یک نقطه شروع است، نه نسخه آماده فروش. لازم است روی نسخه واقعی وردپرس/PHP تست شود و بازبینی امنیتی انجام گیرد. برای استفاده عمومی باید سیاست نگهداری تصاویر و حریم خصوصی، محدودیت مصرف قابل اتکا، لاگ‌گیری بدون داده حساس، آزمون بارگذاری فایل و اعتبارسنجی پاسخ موتور اضافه شود. Nonce به‌تنهایی جایگزین حفاظت کامل در برابر سوءاستفاده عمومی نیست.
